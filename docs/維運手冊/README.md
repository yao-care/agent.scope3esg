## 一分鐘理解整個系統

ESG 公司在 GitHub 安裝這個 App → Worker 自動在其 org 建立 `scope3-inventory` repo（含驗證/計算/儀表板/報表的 GitHub Actions）→ ESG Manager 用 `/admin/:org` 網頁介面（GitHub 登入）設定盤點類別、填供應商 → 系統自動產生每家供應商的專屬填表連結 → 供應商透過表單/API/排程三管道提交碳排資料（每筆 = 一個 GitHub Issue）→ repo 內的 Actions 自動驗證、（審核核定後）計算排放量、更新儀表板、產出報表。資料全在客戶自己的 GitHub repo（資料主權），Worker 只存輕量設定（D1）與佐證檔（R2）。
