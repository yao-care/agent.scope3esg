## ⚠️ 已確認的誤報（別浪費時間修）

### 根因一：ZAP spider 跟著 302 爬到 github.com

`/admin/:org` 未登入會 302 導向 GitHub OAuth。掃描器跟著跳走，**把 github.com 登入頁的
問題記在我們的 URL 名下**。由此產生的誤報：

| 報告項目 | 真相 |
|----------|------|
| Cookie No HttpOnly Flag | 我們的 session cookie 在 `src/routes/admin.ts` 一直都有 `HttpOnly; Secure; SameSite=Lax`。ZAP 抓到的是 GitHub 的 cookie |
| Cross-Domain JavaScript Source File Inclusion ×5 | GitHub 登入頁的 JS |
| Timestamp Disclosure - Unix | 2026-07-15 實測 `/admin/yao-care` 與 `/admin/yao-care/login` 回應中**零個 10 位數字**；state 是 base64url(JSON)，payload 只有 `org`+`nonce`、無 exp |
| **整份 seo-report.html** | title 是「Sign in to GitHub」、og:url 是 `github.com`。掃的根本不是我們的站 |

**正解**：在掃描器端把 ZAP scan scope 限制在 `scope3-worker.lightman-chang.workers.dev`，
一次解決上述全部。

**不要**用 `docs/.zap/rules.tsv` IGNORE 這幾條——尤其 `10010 (Cookie No HttpOnly)`
一旦 IGNORE，將來真的掉了 HttpOnly 也永遠不會再報。拿真實防護換報告好看不划算，
而且這幾條都是 Low/Info、本來就不影響 Quality Gate。

### 根因二：SEO 掃描不適用於本專案

本站是 B2B 內部工具：`/admin` 需登入、`/submit` 需 token，**無公開內容**。
SEO/E-E-A-T/SGE 指標對它沒有意義（且 robots.txt 現在是 `Disallow: /`）。
建議把 SEO 掃描從本專案的 pipeline 移除。

### 根因三：掃描器自身的統計瑕疵

- **SSDLC「0/0」被 compliance 記為 PASS**——實際是一項檢查都沒跑。
- compliance 摘要卡片（10/2/4/5 = 21 項）與 Policy Compliance 那列（Pass:2 Partial:2
  Fail:3 N/A:2 = 9 項）**數字對不上**。
- SBOM 顯示 `Total 314` 但 `Node.js: 0`——明明是 Node 專案。
- compliance 聲稱「ISMS 文件已遷移至 `isms/` 目錄」，但**本 repo 與所有 yao.care 專案
  都沒有 `isms/`**，報告裡 PRO-001/002/003 也全是 `<span>` 而非連結。屬模板死文字。

## ⚠️ Quality Gate FAIL 的算術陷阱

2026-07-14 那次 `High = 15` → Gate FAIL。拆開來看：

- **SAST 14**：Semgrep 原始輸出**全部是 `[WARNING]`**，被掃描器升級成 High 計入門檻
- **Trivy 1**：hono CVE-2026-54290（真 High）

**14/15 的 High 是嚴重度映射造成的。** pin SHA 本身該做，但「WARNING 一律當 High」
會讓門檻長期被雜訊綁架——下次一堆誤報就能再把 Gate 打 FAIL。該檢討
`quality-gate.json` 的映射規則（在掃描器端）。

## 平台限制與其診斷技巧

**workers.dev 的 robots.txt 預設不進 Worker**：Cloudflare 平台層直接回 content-signals
樣板，所以 middleware 的安全標頭套不到它。解法是 `src/index.ts` 自己
`app.get('/robots.txt')` 蓋掉平台預設（已於 commit `b63065e` 實作）。

> 💡 **診斷技巧**：某路徑到底有沒有進 Worker，看它有沒有安全標頭就知道。
> 當初 `/robots.txt` 回 200 卻裸奔，而同樣不存在的 `/sitemap.xml` 回 404 反而標頭齊全
> ——差別就在前者沒進來。
